# Qualia

> Qualia is a digital real estate closing platform for title, escrow and settlement companies. The Qualia API is a partner-gated, read-write GraphQL API at https://api.qualia.com/graphql, authenticated with HTTP Basic credentials issued per organization and scoped by capability gates. This file was generated by API Evangelist from the qualia-title profile; Qualia does not publish its own llms.txt.

Access requires an agreement with Qualia; the schema and developer hub are not public, and anonymous introspection returns 401.
